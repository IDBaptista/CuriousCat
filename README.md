# CuriousCat
O Projeto CuriousCat do curso Desenvolvimento de Sistemas (4° Semestre) foi uma prática nas linguagens JavaScript, HTML e CSS.

# FINALIDADE
Desenvolver a partir dos conhecimentos e pesquisas sobre JavaScript, HTML e CSS um site, utilizando uma API de escolha própria. 
Foi desenvolvido individualmente e foi criado a CuriousCat, uma plataforma interativa que mostra fatos curiosos sobre felinos
